1. Interactive KPI Card Filtering & Look-up Filter Bar (My Training)

KPI & Look-up Filtering
  • Clicking any KPI summary card (Total Assigned, Not Started, In Progress, Overdue, Completed) highlights the active card and filters the My Training table below to matching records; clicking again resets to All.
  • Added the CollabCRM Look-up Filter (Σ ⌄) & Quick Search (🔍 ⌄) bar in a dedicated full-width filter row directly above the table.
  • Look-up fields for Employee view: Training Name, Category, Assigned By, Status, Assigned Date, and Due Date, supporting Contains / Is operators, live value suggestions, multi-token AND pills, and + / Clear.

2. Clean Course Tabs & Label Refinements

UI & Navigation
  • Removed numeric prefixes from Employee course tabs: Overview, Learning Resources, and Assessment & Questions.
  • Removed the word Strictly from passing criteria text (now displays > 80% to pass / configured passing score).
  • Removed redundant type labels where requested and aligned Learning Resources rows cleanly with Module, Resource Title, Type, Resource URL, and Action.

3. Modules-First Sequential Flow & "Go for Assessment" CTA

Modules-First & Go for Assessment
  • Disabled Assessment Tab Until Modules Finish: The Assessment & Questions tab is disabled (🔒 locked, non-clickable) until all learning modules in Learning Resources are marked completed.
  • Sequential Module Completion: Only the next pending module shows Mark Done; subsequent modules show Pending; finished modules show Completed ✓.
  • Go for Assessment Button: As soon as all learning modules are completed (e.g., 2/2 Modules Finished), a right-aligned Go for Assessment → button appears below the Action column in Learning Resources and navigates directly to the unlocked assessment.
1. Complete All Learning Modules → 2. Click "Go for Assessment →" → 3. Attempt & Score ≥ Passing % (80%+) → 4. Auto-Completed + Certificate & Skills Awarded

4. Assessment Passing (≥ 80%), Auto-Completion & Recognition

Auto-Complete & Recognition
  • When the employee submits the assessment and achieves the passing score (default 80% or configured passing %), the training is automatically marked as Completed (100% progress).
  • If the training has an associated Certificate and/or Skills configured in Training Recognition, they are automatically issued and credited to that employee's profile, Skill Matrix, and Certificates list.
  • If the employee fails below the passing threshold and attempts remain, a retake option is available; once passed, Assessment & Questions displays the Passed badge.
